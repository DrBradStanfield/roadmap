## Root cause (from the event frames, confirmed in code)

Frames: react-dom commit → `HealthTool.tsx` effect → `swiper-core
updateAutoHeight:709` (`swiper.params.slidesPerView`). The `<Swiper>` renders
only under `isMobile` (`useIsMobile`, a live `matchMedia` listener at 768px).
Widening a desktop window past it unmounts the Swiper; swiper/react's cleanup
calls `destroy(true, false)`, which runs `deleteProps` (removes `params`) and
then sets `destroyed = true`. `swiperRef` is set in `onSwiper` and never
cleared, so the next `formStage` / `supplements` / `documentHistory` change
called into the dead instance. The `activeTab` effect (`slideTo`) had the same
hole.

**PR:** [#120](https://github.com/DrBradStanfield/roadmap/pull/120) —
US-20 AC2. One `liveSwiper()` accessor (null once destroyed) serves all three
call sites; only `updateAutoHeight` ever crashed, `slideTo` self-guards. Prod
LOC on HealthTool.tsx +9/−7; nothing deletable.
