## Proposal (Tier 0, in grant, not built)

parse failure all pool under whatever the browser names them. Add
`tags: { feature: 'chat', stage }` with a closed `stage` list (`request`,
`stream`, `parse`) to the `sendChatMessage` catch. Build it only if 7H
resurfaces; one event does not earn the change.
