## Root cause

`persistYouTubeTurn` inserted `chat_conversations` with
`title: thread.text.slice(0, 80)`. A UTF-16 cut can split an emoji. JSON.stringify
writes the leftover half as `"\ud83d"`, and PostgREST rejects the whole body.

A live probe proved the mechanism. It POSTed to a nonexistent table, so
nothing was written. Lone high or low surrogates answered PGRST102; a full pair
and `\u0000` both parsed. The comment text can't be read from here, so the
trigger for THIS event is likely, not proven.

Impact was small: skip branch, no reply posted, claim kept (no retry, one
event). The conversation, message and match-event rows were lost (0 rows for
that comment id). 29 YouTube conversations stored since 10-06: the path works.
