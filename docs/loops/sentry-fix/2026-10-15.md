## 7794479814 / JAVASCRIPT-REMIX-70 → not-ours

`SyntaxError: Failed to execute 'appendChild' on 'Node': Unexpected
identifier 'as'`, unhandled (onerror), 15:44Z and 15:57Z, one blog article,
one visitor's Chromebook (Chrome 151, Google referer).

Why not ours:

- Only `<anonymous>` frames (1:2957, 1:2973): eval or `Function` code, not
  one of our bundles.
- `appendChild` throws a SyntaxError only when it inserts an INLINE script
  and the parse fails. `as` is TypeScript syntax in that inline text.
- Built `health-site-chat.js` has no script insert, eval or `new Function`;
  our only inserts (`UploadModal.tsx:312`, `drive.ts:189`) set `src`. So an
  extension or eval'd host code injected it.
