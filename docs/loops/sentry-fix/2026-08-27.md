## Tier 0 proposal (7693659330, cron-lock day-skip — ALL crons)

`tryAcquireCronLock` returns `false` on error; every cron caller
(youtube-bot-summary, chat-summary, trending ×2, reminder_v2) treats false
as "another machine won" and marks the day done — a transient error makes
that machine skip its daily job. Whether the job ran at all depends on
another machine winning the lock (machine count unverifiable from this
env). Proposed: 3-state result (or throw) so callers retry the same day.
Touches all 5 callers → proposal, not widened into PR #30.
