## 7861307165 — "Lab import: extraction too_long"

- Warning, tags `feature=lab_import_v2 path=single stopCode=too_long`.
  One event, 06:23:25Z 11-22, POST `/api/lab-import-v2` on drstanfield.com,
  iOS 18.7 Mobile Safari 26.6.1. Crumbs: Supabase 204 and 200, then Anthropic 200.
- Source: `reportExtractionStop` in `app/lib/anthropic.server.ts`, the
  designed one-signal-per-stopped-file (US-15 AC34). The single-file call
  is not streamed, times out at 60 s, and caps output at
  `SINGLE_FILE_MAX_TOKENS` = 10000. The answer filled it. The first
  `too_long` since the signal landed on 10-19.
- `product_events` (counts only): one guest ran three uploads 06:05-06:18Z
  and saved 37 rows (`valuesDropped` twice, `valuesLimit` once). The fourth
  run, 06:23:26Z: `picked 1, tooLong 1, failedFinal 1`; its review saved 0.
  That file was lost. No retry followed.
- The guest saw "Not read. The file is too long to read in one go."
  (`upload-text.ts`). It names the reason but no way round it.

Verdict: no AC is violated (US-12 AC9 asks for a plain reason). The stop
works as built. The cost is real but single: one engaged user, one file.
Any remedy is a design call, not a bug fix, so the loop holds. The spec
predicted it: US-12 AC12 says a cumulative report with several dated
columns can run past the 10000 cap; US-15 AC34 names streaming as the
remedy. Since the batch path retired on 11-15 (US-12 AC5a/AC18), every
website file reads at 10000; a 20+ file upload once got 12288.

Options if it recurs (for a Decision issue, not now):

1. Stream the single-file read, so a larger budget fits without the 60 s
   non-streamed timeout. Cost: more code on the extraction path.
2. Split a long file by pages and extract each part. Cost: dedup and
   date logic across parts.
3. Give the web notice the way round the connector's hint already gives
   (`import-hints.ts`: "split it into smaller files and import those").
   Cheapest; does not save the file. A copy change, not a bug fix.

Resurface rule (in the ledger): a 2nd `too_long` event, or
`upload_outcome.tooLong` of 2 or more in any 7 days.
