## Root cause (from event data, then code)

Breadcrumbs: successful Drive syncs 03:51–03:52, then a persist at 04:54 —
62 min later, past Google's 1 h token lifetime. The token-refresh POST (URL
scrubbed by Sentry; identified from the `getToken` stack) failed at network
level within the same second — the PR #11 proxy/edge class in cross-origin
form (edge error responses carry no CORS headers → immediate fetch rejection;
cold-start theory unconfirmed, see gaps). The real defect is the blast
radius: `persist()` caught the error and kept the edits **memory-only** while
the UI still showed "✓ … never leaves your Google Drive". Tab close = silent
health-data loss. Recovery (reconnect mode + merge-up) existed only for
page-LOAD refresh failures, never mid-session.

## Fix — PR #19 (Tier 3 pipeline)
