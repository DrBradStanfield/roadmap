## Root cause (from event data)

Every 6G session is a fresh consent, and the 09-17 hypotheses were (a) the
Drive box left unticked or (b) the OAuth client granting `drive.file` to no
one. Either way the app never checked what was granted: "connected" meant
"tokens exist". Google names the granted scopes on both connect paths —
`scope=` on the redirect URL beside `code` and `state`, and `scope` in the GIS
popup's token response — so the check costs no request.

**PR:** [#119](https://github.com/DrBradStanfield/roadmap/pull/119) — US-09
AC15. `claimRedirectCode` returns the URL's `scope`; `completeRedirect` refuses
a grant without `drive.file` BEFORE the code exchange (no token minted, `?code`
stripped, `DriveGrantRefusedError`); the popup path checks the same predicate
before saving. `app.tsx` shows `ConnectRefusedNotice` above the widget (Try
again opens the picker) and counts `cloud_connect_refused` once wherever the
error is caught (`connectRefusal`, also on the Reconnect popup); it never
reaches Sentry — a box left unticked is the user's move. Failing-first tests
(2 → 0, then 6 + 2 after the rewrite), widget + server `tsc` clean. Under (b)
the message still leads to the right action (re-consent) but the user cannot
succeed; the `cloud_connect_refused` rate against `cloud_connect_success`
after deploy is the discriminator this run could not read.

## Escape analysis

No test covered the redirect return or the popup grant (US-09: "Adapters +
PKCE + picker flow remain untested"); AC13's tests began at "the read fails",
one step after the grant. Data shape, not code path: the app treated the
token's existence as the grant. Compounding half: AC15 + `drive-grant.test.ts`
+ `connect-refused.test.tsx`, and the LEARNINGS rule that came out of the
/simplify pass — before adding a probe request to learn a fact, check whether
the provider already handed it over. My first draft probed Drive after the
exchange and classified any 401/403 as "box unticked"; the altitude reviewer
found the URL parameter, which removed a request, a token write and a false
refusal on a quota 403.
