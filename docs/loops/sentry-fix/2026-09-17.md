## Root cause (from event data)

Widget event, `platform=javascript`, unhandled rejection. Stack: `main`
(app.tsx:111) → `initRoadmapStore` → `RoadmapStore.create` →
`SyncManager.load` → `GoogleDriveAdapter.read` → `driveFindFileId` →
`fail` (drive-rest.ts:74). Breadcrumbs: `POST health-tool-app.fly.dev` 200 at
13:04:25.154Z (the refresh through the exchange endpoint), then `GET
www.googleapis.com` 403 at 25.595Z. So the refresh token is alive and the
grant lacks `drive.file`: Google's granular consent screen lets the Drive
box stay unticked, and nothing in the app checks the granted scope. Every
later load repeats it (refresh OK → 403), and `main()` has no catch around
the first read, so `createRoot(...).render` never runs: the mount stays
empty for that user on every visit until they clear site storage. Event
pairs at the same second are two page loads or two readers; the retries
(3-6 per session) are the user reloading a blank widget.

Why now: PR #73 (allowUrls) deployed 09-10 06:37Z; these events were being
dropped by the SDK before it (`[gap][sentry]` learning, burst predicted).

## Escape analysis

`standalone/app.tsx` has no test at all (US-09 status line: "Adapters + PKCE
+ picker flow remain untested"), and `main()` is a top-level `void main()`
with three awaits before `createRoot` — nothing pinned what happens when one
rejects. The Drive adapter's own tests cover a refresh that fails; none
covers a refresh that succeeds on a grant the provider then refuses, because
the app's model of "connected" was "tokens exist". Data shape, not code
path: Google's granular consent produces a token the app never imagined.
Compounding half: US-09 AC13 + `load-fallback.test.ts` (six cases on the
real store) + the `[class][widget]` LEARNINGS entry naming every pre-render
await as a blank-widget path, with the breadcrumb tell for the scope case.
Not fixed, proposed: refusing the unticked grant at connect needs Google's
`scope` field passed through `app/routes/api.google-token.ts` (one
whitelisted field) — an OAuth exchange route, outside the grant.
