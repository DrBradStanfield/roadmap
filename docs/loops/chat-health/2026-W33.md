## Proposals needing Brad (Tier 0 — propose only)

1. **Router: soft-truncate handles instead of rejecting** (`app/lib/chat-router.server.ts`). 3 empty-handles this week were the router *succeeding* then being voided. The existing sanitize block normalises format but not count; Zod `.max(3)` then throws. Ready-to-apply diff:
   ```diff
        rawParsed.handles = rawParsed.handles
          .filter((h): h is string => typeof h === 'string')
          .map(h => h.trim().toLowerCase().replace(/[^a-z0-9-]/g, ''))
   -      .filter(h => h.length > 0);
   +      .filter(h => h.length > 0)
   +      .slice(0, 3);
   ```
   Same graceful-degradation pattern as the block's own comment. Suggested test: raw output with 4 valid handles → first 3 survive, no `router_error`.
2. **YouTube: give the router (and classifier) the video context.** `runPipeline` calls `classifyMessage(sanitized)` / `routeQuery(sanitized)` with the bare comment — unlike web chat, no first/recent context. Oblique comments ("Any chance it might cause blindness?") are unroutable without it. Suggested: pass the companion blog title, e.g. `routeQuery(sanitized, sanitizeForRouter(entry.title))`. Needs a harness check that added context doesn't hurt precision before shipping.
3. **Product call: should the YT bot keep replying to pure rants?** ~5/24 YT empties are rants/reactions. Today the bot replies (engagement by design). If you'd rather it skip them, that's a classifier-prompt change (my scope: propose only). If replying is intended — no action, and the catchable-share metric stays honestly low.
4. **Stale harness case**: "what is my ldl?" (cardiovascular) expects router handles, but since 08-07 the classifier skips it (MEASUREMENT) — production never fires the router. My scope on test-queries.json is append-only; suggest recategorising it to a classifier case.
5. **Delivery contradiction**: constitution says "No email by default… Never Gmail drafts" (2026-08-10); this charter's Delivery section still mandates a Gmail draft (also touched 2026-08-10 by you). This run followed the charter (draft created, never sent). Please reconcile — I lean constitution (kill the draft; the committed report + this proposals section suffice).
